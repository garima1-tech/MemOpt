Per-unit latency and MLP (AOL inputs)

No profiler here can attribute latency to data units (that needs PEBS/IBS sampling). In fallback mode latency is a labelled synthetic assumption and MLP is estimated from the measured access pattern. In measured mode they stay unavailable.

Memory placement

simulated FAST/SLOW are two folders on one disk (fast_memory/, slow_memory/). Moving a unit does not move PostgreSQL pages or physical memory. A data unit is a fixed primary-key range of one table (e.g. orders_s03 = order_id 6001–8000).

Hotness vs AOL

Each dot is a data unit. Far right = hot. High up = each access stalls a lot. MemOpt favours the top; hotness favours the right.
